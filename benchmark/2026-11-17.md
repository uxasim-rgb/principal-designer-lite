# Benchmark run, 17 November 2026

A single maintainer run. Treat it as a smoke test, not a measured quality claim.

## Setup

- **Skill version:** the pre-release state of this repository on 17 November 2026 (before the first commit, 1a305b7). Later fixes are not reflected.
- **Harness:** Claude Code subagents, driven by the skill-creator eval workflow. Not `claude plugin eval`.
- **Model:** Claude Opus 5.5 for the task runs and for grading. The grader is an LLM reading each run's output; there is no human judge.
- **Arms:** with the skill (its folder path given to the subagent) and without any skill. Same prompts, same tools.
- **Runs:** one per case per arm. No repetitions, so no variance estimate.
- **Cases:** the 12 in `evals/`, 63 graded checks in total.

## Known limits

- **Baseline reuse.** The without-skill outputs came from an earlier run with an older set of checks and were regraded against the current checks by a different grader, which was more lenient on one spacing check.
- **Timing and tokens are not reported.** Nine of the twelve with-skill runs were interrupted by a rate limit and resumed, so their timing covers only part of the run.
- **No browser evidence is required by any check.** The landing-page checks read the HTML and the transcript; none of them open the page, test reflow or use the keyboard. Claims about rendering in this run come from the agents' own reports.
- **Weak checks flagged by the grader:** video-only passes without usable depth advice; proportional-copy passes on the invalid case alone; combobox has no phone or touch check.
- **Contamination.** One with-skill run read one line of a case file from the development folder. The installed copy has no `evals/` folder.

## Losses and what changed

- agent-action-authority: the run kept a single actor field instead of separate drafter and approver, and scoped supplier notification out. `references/ai-agents.md` was updated after this run.
- urdu-rtl-review: the run left the balance inside `overflow: hidden`, so it could clip at large text. The Urdu reference was updated after this run.
