# Anti-slop: avoiding generic AI-looking design

AI-generated interfaces drift toward the same look: technically fine and instantly forgettable, or worse, recognisably "made by a model". People notice, and it lowers trust in the product. Treat this list as a review pass before you show any visual work.

## The quality bar

A good result looks like a specific product made by a team with taste for a real audience. Ask yourself:
- Could I swap the logo for any other startup's and nothing else would change? If yes, it is generic.
- Is there one clear thing on this screen to look at first?
- Does every element earn its place, or is something there because "landing pages have one"?
- Would a senior designer remove anything? Remove it first.

## Visual tells and what to do instead

| Tell | Why it reads as slop | Do instead |
| --- | --- | --- |
| Purple-to-blue or rainbow gradients on hero, buttons, text | The single most common AI default | Flat color from a deliberate palette. One accent. |
| Glassmorphism, glow, blurred blobs behind content | Decoration covering a lack of idea | Solid surfaces; let typography and layout carry it |
| Everything in cards, cards inside cards | Boxes replace actual hierarchy | Use spacing and alignment to group; use a card only for a real object |
| Every element has border + shadow + radius | No restraint, muddy depth | Pick one separation method per level |
| Three equal feature boxes with an icon each | Template filler, says nothing | Show the product doing the thing; vary emphasis |
| Emoji as icons, or random icon styles | Looks unfinished and inconsistent | One icon set, one stroke weight, or no icons |
| Everything centered | No reading line, no hierarchy | Left-align body content; center only short heroes |
| Huge radius on everything (20px+) | Toy-like, generic | Smaller, consistent radius family |
| Gray text on colored background, low-contrast "subtle" text | Fails contrast, looks washed out | Check 4.5:1 |
| Fake dashboards full of random charts | Decorative data nobody needs | Show real, specific data that matches the story |
| Stock 3D illustrations, floating devices at angles | Generic SaaS look | Real screenshots, real photography, or nothing |
| Dark mode with neon accents by default | Cliché "tech" signal | Choose the theme for the audience and context |
| Too many font sizes and weights | No system | 4 to 6 sizes, 2 to 3 weights |
| Badges, pills and tags everywhere | Noise competing for attention | Use only where status really matters |

## Copy tells and what to do instead

| Tell | Do instead |
| --- | --- |
| "Unlock the power of...", "Supercharge", "Seamless", "Revolutionize", "Elevate", "Effortless", "Next-level", "Game-changer" | Say what the product does, concretely |
| "Welcome to the future of X" | State the outcome for a specific person |
| A clever or metaphorical headline that only makes sense after reading the subhead | A literal headline: what it does, for whom. Save wit for the subhead or a later section |
| Triplets everywhere ("Fast. Simple. Secure.") | One specific claim with proof |
| Em dashes sprinkled through every sentence | Commas, colons, full stops |
| "Whether you're a X or a Y..." | Talk to the actual audience |
| Invented testimonials, logos, user counts, star ratings | Use real ones or leave the section out and mark it as a placeholder |
| Lorem ipsum or "Feature one" | Write realistic content; content shapes layout |
| Exclamation marks in UI messages | Calm, plain statements |
| Restating the heading in the paragraph below it | Each line adds new information |

## Structural tells

- Every page is hero, logo strip, three features, testimonials, pricing, FAQ, CTA. Use only the sections this product needs, in the order its buyer's questions arrive.
- The happy path only. Real products show empty, loading, error and long-content states.
- Settings and edge screens left as afterthoughts. They are where users get stuck.
- Placeholder data with perfect lengths. Test with long names, big numbers, missing values, other scripts.

## Fixing it

1. Remove decoration until something breaks, then add back only what was needed.
2. Pick one signature element (a typeface, a color, an image treatment, a layout move) and repeat it with discipline.
3. Replace generic content with specific, realistic content.
4. Re-check hierarchy: squint at the screen; the first thing you see should be the most important.
5. Re-check accessibility: contrast, focus, sizes.

Flat, clean and restrained is a strong default. Expressive work is welcome when it is deliberate, consistent and serves the brand, not when it is the model's habit.
